# Intro Component with Sign Up Form

This project is a responsive **intro component with a sign-up form**, built as part of a **Frontend Mentor** challenge.
It focuses on layout, responsive design, form UI, and client-side validation feedback.

## 🚀 Features

- Responsive layout (mobile-first)
- Semantic HTML5 structure
- Custom form UI with validation states
- Error indicators with icons and messages
- Clean and scalable CSS architecture
- Custom fonts and CSS variables
- No frameworks — **pure HTML, CSS & JavaScript**

---

## 🛠️ Built With

- **HTML5**
- **CSS3**
  - Flexbox
  - Media queries
  - CSS variables
  - Custom fonts (`@font-face`)
- **Vanilla JavaScript**
  - DOM manipulation
  - Regex-based form validation
  - Dynamic error handling

---

## 📐 Layout & Design

- Mobile-first approach
- Background image switches between mobile and desktop
- Two-column layout on desktop
- Visual hierarchy using typography and spacing
- Clear UX feedback for form errors

---

## 📋 Form Validation

The form validates the following fields:

- **First Name**
- **Last Name**
- **Email**
- **Password**

Validation includes:
- Empty field detection
- Email format validation
- Password strength rules
- Visual feedback (border color, error icon, error message)
