## ⭐ Featured Project — Vanilla JavaScript SPA

### 🌍 REST Countries SPA (Vanilla JS)

**Live Demo:**
[https://will26developer.github.io/web-projects/frontend-mentor/frontend-mentor-03/#/](https://will26developer.github.io/web-projects/frontend-mentor/frontend-mentor-03/#/)

**Source Code:**
`/frontend-mentor/frontend-mentor-03`

This project is a **Single Page Application built entirely with Vanilla JavaScript**, inspired by the *Frontend Mentor – REST Countries API Challenge*.

Unlike most implementations that rely on frameworks such as React, this version was intentionally developed **without frameworks** to demonstrate a deep understanding of how SPAs work under the hood.

#### 🔧 Key Features

* SPA navigation using **hash-based routing**
* Dynamic rendering of list and detail views
* API consumption using `fetch` and `async/await`
* Search and region filtering
* Dark / Light mode using CSS variables
* Responsive, mobile-first design
* Error handling and fallback views

#### 🧩 Architectural Highlights

* **Hybrid rendering approach**:

  * Static HTML for layout and accessibility
  * Dynamic JavaScript rendering for data-driven content
* Clear separation of concerns:

  * Data fetching
  * Filtering logic
  * Rendering logic
  * Routing logic
* Manual state handling without external libraries
* Efficient DOM updates using `DocumentFragment`

This project demonstrates the ability to **build a real SPA from scratch**, understanding what modern frameworks abstract away.
